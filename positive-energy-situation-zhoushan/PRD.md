# 舟山自定义周报需求

## 1. 产品概述

在“正能量热点报告—自动报告—周报”增加自定义周期查询，支持生成、预览、下载、保存及删除自定义报告，满足固定周报周期之外的统计需求。

报告内容、数据来源、统计口径及自动生成任务沿用线上；历史报告和现有列表能力不变，不新增报告指标。

本地原型以独立演示明细验证自定义周期，保存结果仅保留在当前浏览器，不代表线上真实数据。

## 2. 全局交互规则

- **权限**：复用租户“周报”权限点；只有勾选周报的租户显示自定义查询按钮。未开通时不展示查询表单、不能生成，不新增权限点。
- **入口**：查询按钮仅在自动报告的周报页显示，表单默认收起；展开、收起保留所选日期，切换日报或人工报告后收起。
- **时间**：仅选择日期。报告卡片、预览及下载的起止时间固定显示16:00；实际按北京时间开始日16:30（含）至结束日16:30（不含）统计，保留与自动任务一致的30分钟冗余。
- **筛选隔离**：发布时间筛选只影响报告列表，自定义日期只影响生成范围；两者互不覆盖。已保存自定义报告以首次保存时间参与原列表筛选、倒序排序与分页。
- **异常反馈**：日期错误就地提示；生成、保存或删除失败时保留当前内容并可重试。真实无数据与数据缺失区分展示，不以缺失值充当0；不完整结果在预览、下载和保存中保留相同提示。

## 3. 功能模块：自定义周报

### 3.1 查询与生成

| 字段／操作 | 展示与交互 | 规则 |
|---|---|---|
| 自定义时间查询 | 点击展开／收起表单；生成中禁用 | 不改变历史列表，不直接生成报告 |
| 开始时间、结束时间 | 日期选择框，必填、可修改及清空，不显示时分 | 开始日期须早于结束日期，不限制七天；本地默认2026-10-21至2026-10-28 |
| 查询并生成报告 | 校验通过后生成，显示“正在生成…”；期间日期输入及重复生成禁用 | 沿用原周报统计规则，仅替换实际查询时间区间；不按天数比例拆分已有整周结果 |
| 预览与下载 | 成功后直接打开预览，支持下载和关闭 | 复用已有报告内容；下载与预览一致，不另设生成结果卡片，不自动保存到列表 |

日期为空或无效时提示“请选择完整、有效的开始日期和结束日期。”；同日或倒置时提示“开始日期必须早于结束日期。”。范围无数据时显示空结果；数据覆盖不足或传播量缺失时明确标注，不推算完整结果。

### 3.2 保存与删除

| 操作 | 行为与结果 |
|---|---|
| 保存到列表 | 位于预览“下载报告”旁，保存当前结果；成功提示并置为“已保存”，列表新增带“自定义”标识的报告卡片 |
| 再次查看 | 点击卡片打开保存时的报告，可下载，不重新统计；刷新后保留已保存报告 |
| 重复保存 | 同一生成结果只保存一次；相同周期重新生成的报告可分别保存，互不覆盖 |
| 删除 | 仅自定义卡片提供入口；显示“确定删除这份自定义报告吗？”及取消、确认删除按钮。确认后仅移除选中报告，取消不改变列表；原自动报告不可通过此入口删除 |

保存、删除保留当前发布时间筛选，列表计数与分页同步更新；筛选未包含新保存报告时提示。未保存结果不进入列表，保存失败不显示为成功，删除失败不移除卡片。

### 3.3 验收标准

1. 开通周报权限可见查询按钮，未开通不可见且不能生成；默认收起，展开收起不修改列表。
2. 日期必填且开始早于结束，支持非七天周期；发布时间筛选与自定义区间相互独立。
3. 实际16:30起点纳入、终点排除，相邻周期不重复；报告仍显示16:00，已有报告内容及口径不变。
4. 生成成功直接预览，下载结果一致；无数据、覆盖不足及缺失状态明确，失败可重试。
5. 保存后显示自定义标识，同一结果不重复保存，刷新可复查；确认删除只移除所选自定义报告。
