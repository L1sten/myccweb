# 宁波市融媒协同传播平台 · 模块演示说明

## 导航与页面

顶部五个系统可展开二级入口。当前页面所属系统显示浅蓝底及加粗文字。点击入口在本页展示；点击遮罩、再次点击同一系统或按 Esc 收起抽屉。关闭后焦点返回触发按钮。

传播数据评估保留左侧菜单；其他系统使用完整内容宽度。切回评估时保留筛选、编辑值和账号选择。平台标题统一为宁波市融媒协同传播平台，媒资场景内部名称为宁报智能媒资系统。

## 推荐演示顺序

1. 从传播数据评估进入选题报道，切换状态，搜索“宁波”，打开一项任务详情并返回。
2. 查看素材征集的进度与参与单位；进入联合策划查看时间安排及进展记录。
3. 进入全市资源库，再展示素材中心、搜索中心和审批中心。
4. 展示主题监测与传播分析的宁波场景，进入实时热搜切换平台和查看话题。
5. 展示四个AI工具页面，最后返回媒体评估继续原有演示。

## 演示边界

协同模块支持状态、关键词、单位、日期筛选及分页，创建与上报仅提示敬请期待，不会写入正式系统。协同内容和热点榜单为演示数据，截图内指标也仅作场景展示。AI页面不会执行真实生成或审校。

本次仅本地更新，不包含提交、推送或上线。既有月度编辑值和发布历史不做迁移或清除。

四个媒资页面不显示额外的模块标题栏，截图直接接在平台顶栏下方。

灵思助手、智能写作、智能审校、视频创作截图页同样不显示额外模块标题栏，截图直接接在平台顶栏下方。

主题监测与传播分析也不显示额外模块标题栏；所有截图页直接接在平台顶栏下方。
