# 宁波市域一张网传播数据与评估演示

本原型对应《（实际建设清单-V2）宁波市域一张网建设清单及报价》第五部分，供项目汇报及前后端讨论使用。三个模块可在同一入口切换，所有媒体运营数字、作品、评分和榜单均为模拟数据，不代表真实经营表现或正式考核结果。

## 访问

在线入口：https://l1sten.github.io/myccweb/ningbo-media-evaluation/

当前目录为静态发布产物，包含入口、脚本、样式、地图资源与配套说明。业务操作与本地演示一致，刷新恢复初始状态；不接入后台。维护源工程保留在本地“宁波一张网/outputs/传播评估演示”。

本地查看发布产物时，在上级仓库目录运行 `python3 -m http.server 5180 --bind 127.0.0.1`，打开 `http://127.0.0.1:5180/ningbo-media-evaluation/`。

## 推荐演示路径

1. 在数据看板浏览核心指标、内容趋势及地图，打开一条10月7日发布的报道，查看“待观察”的第2、第3日。
2. 切换平台运营明细，选择微信及“慈溪发布”，切换9月、月统计、累计等条件，查看账号数据。
3. 进入媒体评估，打开“海曙区全媒体中心”的内容产能，查看下降提醒；在整改跟踪提交计划，演示退回修改、审核通过和100%完成。
4. 在指标溯源提交复核或修改归属，再返回榜单发布本地结果，查看历史快照、导出结果及下载月报。
5. 在账号对标选择省级“潮新闻”和本地同平台账号，切换比较指标并查看作品。

## 数据与交互口径

- 固定演示日期为2026年10月7日。概览以该日及截至该日的10月数据展示；媒体评估默认最近完整月2026年9月，对标同为9月。
- 本地48个账号共用一份数据。9月计数类数据按基准的0.91取整；8月、7月评估原始数据再按对应历史系数缩放。粉丝数为同一演示快照，人均时长按秒展示；均值及存量不作周期累加。
- 发布次数表示发布动作，发布篇数表示内容条数，演示次数低于或等于篇数。曝光与全网传播分属不同范围、不同统计周期，不互作加总。
- 日趋势显示最近7日；月趋势显示截至所选月的6个月。周期数据展示该期量，累计数据演示年初至该月；客户端日活和时长保持均值口径。无同比母数或尚未采集的场景不得当作0。
- 原创类型总量为538条，分类合计一致；情感比例为82.6%、14.8%、2.6%，合计100%。地图明细汇总与覆盖数、传播总量一致。
- 关键词及最新报道每12秒模拟轮换，可暂停。其余分区标明每日更新；没有外部采集或真实定时任务。
- 综合评分使用预置30/30/40示例结构；分项合计即总分。内容产能原始数量排序赋分、指定媒体基础及超额规则、平台标准化方式尚待正式口径，不在原型中冒充已确定规则。
- 微信“在看”、微博“评论”为运营观察，不加入平台评分。账号对标的互动量则按平台适用指标汇总，二者用途不同。
- 评估的“平台”筛选筛出拥有该平台账号的媒体，综合榜仍展示媒体全口径得分；单个平台得分在详情查看。筛选保留全市排名。
- 修改归属会更新当前会话的账号关系与单位账号列表，但不会重算预置评分；已发布版本保持发布时快照。
- 复核演示到“待处理”记录；整改可完整走到完成。发布仅创建本地快照，不通知外部人员。
- 所有修改、复核、整改和发布状态仅保留在本次会话内。刷新页面恢复初始数据；无登录、真实权限、后台写入或公网发布。

## 源工程维护位置

- `src/data.js`：单位、账号、对标库、内容数据。
- `src/Dashboard.jsx`、`src/Evaluation.jsx`、`src/Benchmark.jsx`：三个业务模块。
- `src/styles.css`及模块样式：政务蓝、浅底白卡、紧凑表格。
- `public/data/china.json`：阿里云DataV公开地图数据，来源 https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json 。地理轮廓为静态资源，传播数值是模拟数据。
- 发布版本仅包含运行资源与说明，完整源工程、测试及验收记录保留在本地原型目录。

原型与本说明作为同一套材料交付。后续变更指标、按钮状态或演示范围时，应同步维护两者。
