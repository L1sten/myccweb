# 宁波市域一张网 · 传播数据与评估中心

对应建设清单第五部分，包含数据看板、媒体评估与账号对标。界面采用正式系统文案；本项目仍为前端原型，运营数字及评分输入来自本地数据，不能视为真实媒体表现或已获主管部门确认的正式考核结果。真实稿件的标题、媒体、日期、原文地址单独维护，不冒充真实传播分析数据。

## 运行与交付

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 5173
npm run build
node --test tests/data.test.mjs tests/scoring.test.mjs tests/articles.test.mjs
```

本地入口：http://127.0.0.1:5173/ 。构建产物为 dist/client，使用HTTP服务访问。线上入口：https://l1sten.github.io/myccweb/ningbo-media-evaluation/ 。配套说明和原型作为同一套材料维护。

## 评分规则 2026.1

建设清单规定三个评价维度、原创排序赋分、刊发基础及超额机制，以及四个平台的计分指标。以下具体权重、阈值、排名换算和缺失处理为本次方案设计参数，并非从历史考核截图或正式政策中推导。

1. 综合得分为内容产能、权威刊发、全网传播三项已显示得分之和，上限30/30/40分；各项四舍五入保留两位小数。
2. 排名得分率=(N-r)/(N-1)，r为降序平均秩，并列取占据名次的平均值。N为全市对应指标的有效参评数量，缺失值暂不进入该指标排名，补齐后重算；筛选不改变参评池。零值计0，单个有效正值对象得满分。
3. 原创数量按单位、自然月及稿件ID去重；内容产能分=原创排名得分率×30。每日原创独立维护，连续7个自然日逐日下降触发提醒，持平中断、不额外扣分。
4. 权威刊发按“稿件ID+指定媒体ID”去重；不同指定媒体分别计次。基础分按中央0.6、省0.3、市0.1分/篇相加，上限24分。超过月度10/20/40篇后的部分，分别额外加0.15/0.08/0.03分/篇，额外分上限6分；两类额度独立封顶。
5. 客户端端内日活/端外日活/人均时长权重40%/20%/40%；微信和微博阅读/点赞/转发40%/30%/30%；抖音点赞/评论/转发40%/30%/30%。账号每项分=同平台排名得分率×权重×100，账号总分为各项之和。微信在看和微博评论仅观察。
6. 单位同平台全部账号等权平均；平台平均分保留两位小数，再乘10%得单位平台贡献，四项贡献相加得到全网传播分。未开设平台计0且不重新分配权重；应采集指标、原创或刊发记录缺失时标为待补齐，暂不排名并禁止发布。
7. 综合同分采用1、1、3竞争排名；展示次序按原创、刊发、传播得分降序，最后按单位编号升序。排名变化=上月全市排名-本月全市排名。同类按市级与区县分组。
8. 调整归属即时重算未发布结果。发布深拷贝并冻结原始数据、账号归属、全市参评池、分数、筛选范围与规则；历史版本不随后续调整变化。报告与导出直接使用同一结果集。

## 数据与真实稿件边界

- 固定统计日2026-10-07；评估与对标默认2026-09。评估支持9/8/7月，历史同期使用对应月份输入重新计算，不缩放预置得分。
- 48个本地账号共用原始指标；9月计数系数0.91，8月0.91×0.94，7月0.91×0.89；粉丝存量、人均时长保持基准值，不随计数缩放。客户端日活按月内日均口径展示。
- 原创及刊发分别维护按月原始记录，其中含重复采集记录用于验证去重。每日原创汇总与月度去重条数一致。
- 看板的内容产能、地图、情感及账号对标库为独立模拟统计；地图轮廓来自阿里云DataV公开地理数据。全市产能、曝光和全网传播对应不同统计范围，不跨口径加总。
- 作品库已核对7篇真实稿件：10月甬派3篇、9月甬派2篇、人民日报客户端1篇、潮新闻1篇。账号、平台、月份严格关联，无对应稿件时显示空状态；不得将网页转载媒体改写为所选账号。链接在新标签打开；第三方可能更改内容或限制访问。
- 作品传播数字是单独的本地输入。观察窗口按发布日期至统计日计算，未到日期显示待观察；已观察日的数据按固定比例归一化分配，累计与当前作品阅读数相等，不展示未来日数值。9月作品统计截止9月30日。
- 关键词和报道每12秒轮换；其余按每日更新口径展示，但无真实采集服务。
- 复核保存待处理记录；整改支持提交、退回、审核、进度更新和完成。所有状态仅在当前会话有效，刷新恢复；业务结果发布不向外部人员发送消息。

## 浮层与原文入口

作品列表不展示内容摘要或统计口径尾注。点击三个模块中的作品标题可进入全屏“传播转载详情”，沿用截图的三栏布局：稿件图文预览、当前传播与转载路径/明细、传播分析报告。原文配图来自对应出版页面，完整正文通过原文链接阅读；没有转载采集记录时显示待采集，不推断转载媒体数。顶部支持打开原文、复制链接及关闭。

媒体评估的“关联作品”弹窗直接展示每篇作品的标题、发布信息、阅读/播放、点赞、转发，并提供原文跳转，不再打开二次传播数据弹窗。账号对标页的代表作品同样直接展示数据与原文链接；数据看板的报道列表、话题关联报道和账号关联内容在当前浮层内展示数据与3日追踪，不再跳转第二层作品详情。首页最新报道保留一次详情入口。弹窗及抽屉右上角为统一32px“×”，标题固定、正文滚动。Escape只关闭最上层，焦点在浮层内循环，关闭后返回触发控件（触发控件因状态变化消失时返回父浮层）。查看类遮罩可关闭，表单遮罩不关闭；有未保存编辑时弹出丢弃确认，取消确认后保留编辑。
